Lightroom Classic Quick Reference — Calendar Archive

Why Classic (not CC)

  • Local-first — files stay on disk, no Adobe Cloud upload. Hundreds of calendar pages don’t need to sync.
  • Watched folder / tethered import — Classic auto-imports from ~/Lumix Tether/ as captures land.
  • ColorChecker plugin — Calibrite Camera Calibration only works in Classic.
  • Export control — file naming templates, output folder targeting, presets.

1. Import

1

File → Import (or Cmd+Shift+I).

2

Left panel: navigate to ~/Lumix Tether/ → select the session date folder.

3

Top center: select Add (not Copy or Move). This catalogs the RAW files in place.

4

Verify photos are checked, then click Import (bottom right).

Always use Add. The RAW files stay in ~/Lumix Tether/. LR Classic just references them.

2. Develop — Minimal Edits

1

Switch to the Develop module (top right, or press D). Select first photo.

2

White balance check — Basic panel, top right. Should be close from in-camera custom WB. If you have a gray panel shot: click the WB Eyedropper (dropper icon), then click on the 18% gray patch. LR neutralizes any remaining cast.

3

Lens Corrections — scroll down right panels, check Enable Profile Corrections. LR should auto-detect the Olympus 60mm.

4

That’s it. Leave everything else at defaults.

Do NOT adjust: Contrast, Clarity, Sharpening, Noise Reduction, Crop, Black & White. Clean, neutral images produce the best OCR results.

3. Sync Settings Across Photos

1

In Develop module, select all photos in the filmstrip (bottom). Cmd+A to select all.

2

Click Sync... (bottom left of Develop module).

3

Check the settings you changed (White Balance, Lens Corrections). Click Synchronize.

Sync applies the first selected photo’s settings to all others. Make sure the photo with your edits is the “most selected” (brighter highlight in filmstrip).

4. Export

1

Switch to Library module (G). Select the photos to export.

2

File → Export (or Cmd+Shift+E).

3

Set the export options per the table below. Click Export.

Export LocationChoose Folder → madonnahist/test-data/samples/
File NamingRename To → Custom Name → type year-month (e.g. 1968-01)
File SettingsJPEG, Quality 95
Image SizingDo not resize (leave “Resize to Fit” unchecked)
Output SharpeningOff (uncheck)
MetadataInclude → Copyright & Contact Info Only (minimal)
Export one photo at a time if they are different calendar months, so each gets the correct YYYY-MM filename.
