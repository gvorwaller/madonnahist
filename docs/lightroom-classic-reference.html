Lightroom Classic Quick Reference — Calendar Archive

LR Classic is not in the default workflow. The camera shoots RAW+JPEG. Copy the JPEGs directly to madonnahist/test-data/samples/ and rename to YYYY-MM.jpg. LR Classic is only needed if you want to batch-correct white balance from the gray panel (e.g. lighting drifted between sessions, a batch looks off).

When to use Classic

  • WB correction — eyedropper the gray panel to fix a color cast, sync across a batch.
  • Catalog / browse — review and cull captures before exporting.
  • Local-first — files stay on disk, no Adobe Cloud upload (use Classic, not CC).

1. Import

1

File → Import (or Cmd+Shift+I).

2

Left panel: navigate to ~/Lumix Tether/ → select the session date folder.

3

Top center: select Add (not Copy or Move). This catalogs the RAW files in place.

4

Verify photos are checked, then click Import (bottom right).

Always use Add. The RAW files stay in ~/Lumix Tether/. LR Classic just references them.

2. Develop — Usually Skip

With controlled studio lighting at fixed 5000 K and custom WB set in-camera, the photos should be neutral out of the gate. The normal workflow is Import → Export with no Develop edits.

Lens Corrections — automatic. The G9 II + Olympus 60mm (Micro Four Thirds) embeds lens correction data in the RW2 file. LR Classic applies it via the built-in lens profile. No manual step needed.

If a batch looks off (color cast, lighting drift between sessions):

1

Switch to Develop (D). Select the gray panel shot from that session.

2

Click the WB Eyedropper (W), then click the 18% gray patch. LR neutralizes the cast.

3

Select all photos from the session in the filmstrip (Cmd+A). Click Sync... (bottom left), check White Balance, click Synchronize.

Do NOT adjust: Contrast, Clarity, Sharpening, Noise Reduction, Crop, Black & White. Clean, neutral images produce the best OCR results.

3. Export

1

Switch to Library module (G). Select the photos to export.

2

File → Export (or Cmd+Shift+E).

3

Set the export options per the table below. Click Export.

Export LocationChoose Folder → madonnahist/test-data/samples/
File NamingRename To → Custom Name → type year-month (e.g. 1968-01)
File SettingsJPEG, Quality 95
Image SizingDo not resize (leave “Resize to Fit” unchecked)
Output SharpeningOff (uncheck)
MetadataInclude → Copyright & Contact Info Only (minimal)
Export one photo at a time if they are different calendar months, so each gets the correct YYYY-MM filename.
