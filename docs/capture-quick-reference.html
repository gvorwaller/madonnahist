1. Lights (Godox SL100Bi)

Color temperature5000 K
BrightnessWhatever lands exposure at 1/60 – 1/125 s (start ~30%, adjust)
Both panelsEqual output, 45° from each side of the page
Not 4000 K (too warm — red ink reads as brown). Not 5600 K (too cool for aged paper). 5000 K is the D50 graphic-arts standard.

3. Saving Custom Mode C1 (on camera body, not Tether)

  1. Dial in all settings from the table above on the camera
  2. Menu → Setup (wrench) → Setting → Save to Custom Mode
  3. Select C1, confirm
  4. From now on, rotate the mode dial to C1 to restore everything instantly
Lumix Tether cannot save Custom Modes — this is camera-body only. Tether controls settings and triggers the shutter during shooting.

4. ColorChecker Passport Photo 2 — Three Surfaces

White panel
(inside, brighter side)		 Sets custom white balance.
Place on easel under both lights → press WB on camera → select Custom White Balance → fill frame with white panel → press shutter to sample. Camera locks neutral reference.
Gray panel
(inside, darker side — 18% gray)		 Verifies exposure.
Fill frame with gray panel. Meter should read ~0 EV at f/5.6, ISO 200. If not centered, adjust shutter speed until it is.
Also useful in Lightroom: eyedropper this patch to neutralize color cast.
Color patches
(flip case over — 24 colored squares)		 Archival color reference.
Shoot one frame per session. Used later in Lightroom with the Calibrite ColorChecker Camera Calibration plugin to build a camera profile that normalizes color across sessions months/years apart.
You don't need the plugin on day one — just shooting the frame preserves the reference.

5. Per-Session Sequence

1

Set up rig on floor marks. Close blinds. Power lights to 5000 K, equal output.

2

Turn mode dial to C1. Connect Lumix Tether. Confirm live view.

3

White panel on easel → set custom WB on camera.

4

Gray panel → verify meter reads ~0 EV. Adjust shutter speed if needed.

5

Flip case → color patches on easel → shoot one reference frame.

6

Manual focus: zoom to 10× in live view on a page, adjust focus ring until ink is sharp. Set once for session.

7

Remove Passport. Load first page. Begin capture via Lumix Tether.

8

After last page: review frames before teardown. Reshoot anything soft or unevenly lit while the rig is still up.
