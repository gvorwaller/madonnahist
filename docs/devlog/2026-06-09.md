- Web app `spaces-upload.ts` uses filesystem storage when `MADONNAHIST_OBJECT_STORE=local`.
- Worker `spaces.ts` reads from the same local filesystem object store.
- Production still uses DigitalOcean Spaces credentials from `private_data.api_credentials`.
- Health check treats local object-store mode as configured.

This enables ingest, un-ingest, grid/warp, and OCR reset tests without touching production Spaces objects.

- Destination: Volume 3 shared folder `madonnahist-spaces-backup/current/`.
- Enable NAS-side snapshots/versioning so production deletes do not permanently erase the NAS copy.

- Avoid DO pushing to the home NAS; it would require exposing the NAS or VPN plumbing.
