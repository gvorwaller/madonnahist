### Key Technical Insight
Three that will recur:
1. **Sequential tests cannot catch TOCTOU** — both CRITICALs from the code review were check-then-act races between the editor, the trigger, and the worker. The durable fixes were *atomic SQL by construction* (`INSERT..SELECT..FOR UPDATE` guards, conditional `ON CONFLICT..WHERE`) rather than more application logic.
2. **Svelte 5 effects tracking `data.X.y` re-run on every invalidation**, not just when `y` changes — any editor state reset must be value-guarded or background refreshes destroy user input (the week's worst user-facing bug).
3. **Safari is a different platform**: buttons don't focus on click (focusout/relatedTarget patterns break), bfcache resurrects stale relative form actions, inline PDF views swallow the tab. Now codified in CLAUDE.md; iPad testing by Gaylon caught what desktop never would.
Also: `ALTER DEFAULT PRIVILEGES` from 0004 silently grants the worker SELECT on every new table — every new migration must REVOKE deliberately (bit twice: 0023, 0024).
