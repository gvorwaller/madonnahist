### Key Technical Insight
The correction lexicon is the linchpin of the pipeline. Family calendars repeat the same ~20 names and ~30 activities across 60 years — the ideal corpus for a substitution table. After ~30 corrections Madonna covers all family names; after ~100 the LLM cleanup is fixing 80%+ of proper nouns automatically. Word-level diff (free, deterministic) is sufficient for the high-frequency substitutions that matter most.

The five-field separation (corrected text vs expanded text vs narrative) preserves archival integrity: faithful transcription stays faithful, interpretation and memories are layered on top without contaminating the source. The notation key table drives auto-expand in the UI so Madonna types `(R)` and never needs to know Unicode.
