### Key Technical Insight
The four text-improvement tables serve different roles: `ocr_vocabulary` = soft hints ("these words exist"), `correction_lexicon` = learned error patterns ("OCR keeps misreading X as Y"), `notation_key` = hard substitutions ("(R) always means Rebekah"), `day_corrections` = human truth. The first two feed the LLM prompt as guidance; notation_key and high-frequency lexicon entries should be applied as deterministic post-processing, not left to LLM judgment. Separating the substitution pass from the LLM worker means you can re-apply rules without burning Claude API credits.
