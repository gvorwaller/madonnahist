3. Lumix Tether & Ingestion Pipeline Workflow

We bypass Lightroom entirely. The camera writes JPEGs directly to the Mac, which are then processed via the Capture Intake UI.

Rig Setup & Calibration Sequence

1

Set up tripod and light stands on their taped floor marks.

2

Adjust tripod hinge to 44″ and light stands to 52″ height.

3

Power lights to 5000 K at 14% brightness.

4

Close window blinds fully to block ambient daylight and avoid mixed illumination.

5

Mount camera, connect USB to Mac, power on, and rotate mode dial to C1.

6

Open Lumix Tether on the Mac to check the live view.

7

Custom WB: Place ColorChecker WB panel flat on easel. Sample custom WB on camera body to lock it in-camera.

8

Exposure Check: Swap in Gray Panel. Verify shutter speed reads between 1/60 – 1/125 s.

9

Manual Focus: Zoom to 10× in live view on a calendar page. Focus manually on the ink. Do not touch focus again.

Capture Sequence

1

Load the calendar page into the table edge guides.

2

Trigger the shutter via Lumix Tether interface (or spacebar / remote release).

3

Confirm the JPEG file lands directly in ~/Lumix Tether/ and check focus/framing in the preview.

4

Place the next page on the cradle and repeat.

5

After the final page, review all captures before tearing down the rig.

4. Ingestion UI Workflow (Gaylon/Admin)

1. File Sync / Discovery

  • Local Mode (Capture Station): The local SvelteKit server reads ~/Lumix Tether/ directly.
  • Production Mode (DO Droplet): A LaunchAgent on the Mac runs rsync automatically every 2 minutes to push JPEGs from ~/Lumix Tether/ to the remote droplet.

2. Capture Intake UI

1

Navigate to /admin/capture on the server page.

2

Click "Classify All" to run the full-page Vision pass and auto-detect month/year headers.

3

Verify or adjust the proposed month/year, check quality indicators (warnings for blur/clipping), and select the appropriate layout grid fit.

4

Select the pages to import and click "Ingest Selected" to upload to Spaces, create DB records, queue OCR cell crops, and move files to completed status.
